# ProAutomation.store

ProAutomation.store is an AI-powered business growth platform designed for agencies, freelancers, and sales teams. It includes comprehensive modules for lead generation, website analysis, AI-powered outreach, CRM, a website builder, and a hot-call marketplace.

## Features (In Development)

1. **Lead Generation & CRM**
2. **AI Website Analysis**
3. **AI Website Builder**
4. **Gmail Integration & Outreach**
5. **Marketplace & Hot Calls**
6. **Advanced Billing & Monetization**

## Tech Stack

- **Framework:** Next.js 15+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, shadcn/ui
- **Database:** PostgreSQL, Prisma ORM
- **Authentication:** Auth.js (NextAuth v5)
- **Background Jobs:** BullMQ + Redis (Planned)

## Setup Instructions

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Copy `.env.example` to `.env` and configure your environment variables.
4. Run `npx prisma db push` or `npx prisma migrate dev` to sync the database schema.
5. Start the development server using `npm run dev`.
